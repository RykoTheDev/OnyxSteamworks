# Embedded fonts

These font files are vendored and embedded into the binary with `include_bytes!`.

- Manrope (Regular/Medium/SemiBold): SIL Open Font License 1.1.
  Source: https://github.com/googlefonts/manrope (variable font, instanced to
  static weights 400/500/600 with fonttools).
- JetBrains Mono (Regular): SIL Open Font License 1.1.
  Source: https://github.com/JetBrains/JetBrainsMono
- Phosphor (Regular/Fill): MIT License.
  Source: https://github.com/phosphor-icons/web

Each upstream project ships its full license text; see the links above.
